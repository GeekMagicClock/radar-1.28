# Radar 1.28 Firmware Downloads


Official OTA firmware archive for the Radar 1.28 device.


This repository contains only customer upgrade firmware and English release notes. It does not contain source code, production files, filesystem images, factory-flash packages, private configuration, or manufacturing material.

**v3.3.5** — [Firmware and release notes](v3.3.5/)


## OTA Upgrade


1. Connect to the device's web interface.
2. Open the firmware update page.
3. Select the `radar-1.28-vX.Y.Z-ota.bin` file for the version you want.
4. Keep the device powered and connected until the update finishes and it restarts.


OTA updates preserve the existing device settings. Do not interrupt power during an update.


> These files are only for the compatible 1.28-inch round Radar device. Installing them on different hardware may make that device unusable.
