# Radar 1.28 v3.2.0

Released: September 24, 2026

## What's New

- Added an Open-Meteo weather screen using the radar location.
- Added English and Chinese weather text, temperature, humidity, daily high/low, and temperature-based colors.
- Added local-timezone support plus rotating Gregorian date, lunar date, solar-term, and festival information.
- Added embedded weather, humidity, and calendar icons with partial screen refresh.
- Long-press now switches between radar and weather, and the selected startup screen is remembered.
- Radar range is now shown at the bottom of the circular display.
