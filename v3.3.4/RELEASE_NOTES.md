# Radar 1.28 v3.3.4

Released: October 8, 2026

## What's New

- Added a dedicated Weather tab to the web settings.
- Weather can reuse the radar location or use independent latitude and longitude.
- Added today/tomorrow forecast selection and Celsius/Fahrenheit settings.
- Added a bilingual Help tab explaining button controls.
- Improved tomorrow-forecast date, lunar-calendar, solar-term, and festival display behavior.
- Existing configurations automatically inherit the radar location for weather.
