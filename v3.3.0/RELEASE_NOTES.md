# Radar 1.28 v3.3.0

Released: October 2, 2026

## What's New

- Added double-click aircraft selection and a cycling aircraft information card.
- Added configurable callsign, manufacturer/type, registration, speed, heading, altitude, distance, and bearing details.
- Added common distance, speed, and altitude unit options.
- Increased the maximum radar range to 100 km.
- Added rotorcraft recognition and a dedicated rotorcraft icon.
- Aircraft types are hidden when the source has no type information.
